# Kodi 21.3 for Hisense VIDAA U4

Kodi 21.3 for the Hisense 55U8QF running `V0000.01.00C.P0219`. DirectFB and Mali GLES 2
render the interface. The TVPlayer core uses the firmware's file player or streams clear
codec packets to a native ES helper, with software playback as a compatible fallback.

## Source and build

1. [Follow the complete cross-build and install guide](docs/01-build.md). It lists the
   Linux host packages, exact Kodi revision and four firmware libraries to obtain
   privately from your matching development TV. It also documents rollback,
   language-pack preparation and activation of `TVPlayer`.
2. [Check the build record](BUILD-RECORD.md) and [source archive digests](BUILD-INPUTS.sha256).
   The reproducible source entry point is the upstream Kodi tag plus our
   [overlay](source/kodi-port/kodi-tree). The [native sources](source/native) include

3. [Verify the included ARM helper builds](prebuilt/README.md). The full

   historical Kodi executable is retained in the private project backup because
   it embeds personal build paths.

## Install Kodi on its own

Use the [cross-build guide](docs/01-build.md) to produce a local
`kodi-tv.tar.gz` for the reference TV ABI. Start, check status and stop Kodi
directly through the documented `kodi.sh` interface after installing. The
Flex tile and watcher are an optional launcher handoff. [Install and activate TVPlayer](docs/01-build.md#4-install-and-activate-the-hardware-player)

Check the [player rule and playback paths](docs/03-frame-rate-and-video.md) with
local clear media before adding launcher controls. Keep the existing runtime
and user-profile backups available for [rollback](docs/06-update-modify-and-troubleshoot.md).

## Master prompt

Open this repository in your coding agent and paste the block. Give it a Linux
x86-64 build environment, your exact firmware and the documented matching
firmware libraries privately. The checked ARM helpers are included here, and
the full TV installer is generated by the build.

```text
Help me build and run Kodi 21.3 on my own Hisense 55U8QF, VIDAA U4 firmware
V0000.01.00C.P0219. I want direct Kodi start/status/stop and playback first.
Treat Flex launcher handoff and Denon integration as optional later steps.
Confirm my exact model, firmware, build host, available space and required
input libraries before touching the TV.

1. Read README.md, BUILD-RECORD.md, BUILD-INPUTS.sha256 and docs/01-build.md
   through docs/06-update-modify-and-troubleshoot.md. Locate the overlay under
   source/kodi-port/kodi-tree, the native helper sources under source/native,
   the build scripts and the TV installers under source/kodi-port.
   Summarize the reference ABI and the purpose of each build input.

2. Build in a clean Linux x86-64 workspace. Check the Kodi 21.3-Omega source at
   commit a3a448d26b8d560a65655dab2cd122994dc4e146, Zig 0.16.0, the ARM
   softfp target and the DirectFB/GLES 2 configuration. Use the four firmware
   link libraries described in the build guide from my matching device, kept
   in a private sysroot. Use my existing authorized access or my already
   supplied private copy for those inputs. If one is missing, report it and
   continue with the host checks that are possible.

3. Check the source archive hashes and prebuilt/SHA256SUMS. Follow the ordered
   build and package steps. If I request the optional German UI, use the
   documented Omega language pack and verify its digest. Produce kodi-tv.tar.gz
   locally. Inspect the ARM ELF32 loader, GLIBC symbol versions, library
   dependencies, archive contents and SHA-256 before proposing installation.
   Record the build log and check public reports for personal paths and data.

4. Present the planned application paths, verified host target and recovery
   method. An existing authorized development session is required for TV
   work. Back up /APPS/kodi and Kodi user state separately and confirm space
   for rollback. Use the guide's verified local installer after I approve
   the deployment. Run a direct status/start/stop smoke test through kodi.sh.
   Merge the documented sample player rule into a backed-up profile when
   testing TVPlayer.

5. Explain how Kodi chooses DMP, clear ES or software playback. Compare
   app0/app2 file-player evidence with the packet-fed app1 design. Explain the
   separate meanings of Linux account, item profile and media session. Use
   project measurements to explain the Netflix observation and the scope of
   the standalone ES evidence. Check with clear clips and record the route,
   frame rate, duration and IRQ counts. Treat panel refresh as its own test.
   Verify seeking, exit, audio and ARC before suggesting launcher handoff.

6. Give me the build artifact path, hash, TV smoke-test results and rollback
   steps. Keep vendor libraries, user profiles and local secrets private.
   Report any remaining hardware checks by name and leave publishing to me.
```
